## Lunara v0.1.0

一个深空 / 星轨 / 月光风格的 PyQt6 桌面音乐播放器。信息架构参考网易云 PC 端，界面全部自绘。

### 这版能做什么

- **播放**：歌单 / 歌手 / 专辑 / 搜索 / 每日推荐 / 私人漫游，音质可实时切换（标准 → 母带）
- **歌词**：原文 + 译文、逐行滚动、滚轮手动翻词、偏移校准、点击跳转
- **本地**：下载（断点续传、并发、限速）、本地曲库（多目录扫描）、从磁盘删除
- **体验**：全屏播放页、播放列表面板、卡片错峰入场、悬停推近、跟随主题的提示框
- **系统**：单实例、托盘常驻、窗口记忆、日志落盘

### 安装

1. 下载 `Lunara-v0.1.0-win64.zip` 并解压
2. 双击 `Lunara.exe`

> 未做代码签名，Windows 可能提示「未知发布者」，选择「仍要运行」即可。首次启动约 3 秒。

### 已知限制

- 仅 Windows x64
- 需要登录才能看到推荐内容（点右上角头像登录）
- 会员曲目非会员只能试听
